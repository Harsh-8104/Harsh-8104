- **🖥️ Portable Offline AI Assistant** — An offline LLM assistant packaged on a USB drive using llamafile and a quantized Qwen model, no internet or API key required.
- **📄 RAG PDF Chatbot (Folio)** — A retrieval-augmented chatbot for querying PDFs, built with FastAPI, LangChain, Pinecone, and Gemini, paired with a single-file vanilla HTML frontend.
